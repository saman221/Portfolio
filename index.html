01 / 04 INTERFACE LAYER

Interface؛ جایی که محصول دیده می‌شود.

ساختار بصری، تایپوگرافی، حرکت و دسترس‌پذیری در یک سطح منظم کنار هم قرار می‌گیرند تا کاربر بدون اصطکاک مسیرش را پیدا کند.

  • Visual System
  • Responsive UI
  • Accessibility
02 / 04 FLOW LAYER

Flow؛ مسیری که اجزا را متصل می‌کند.

رویدادهای کاربر، درخواست‌ها و پاسخ‌ها باید بدون گسست بین رابط و منطق حرکت کنند؛ این لایه همان مسیر قابل‌اعتماد ارتباط است.

  • Interaction
  • Data Flow
  • Integration
03 / 04 LOGIC LAYER

Logic؛ جایی که تصمیم‌ها گرفته می‌شوند.

قواعد محصول، اعتبارسنجی و رفتارهای اصلی در هسته‌ای روشن و قابل‌توسعه شکل می‌گیرند تا پیچیدگی از دید کاربر پنهان بماند.

  • Business Rules
  • Validation
  • Backend
04 / 04 DATA LAYER

Data؛ حافظه‌ی منظم محصول.

اطلاعات زمانی ارزشمند است که ساختار، مسیر دسترسی و ارتباط آن با منطق محصول شفاف باشد؛ این لایه پایه‌ی ماندگاری سیستم است.

  • Structure
  • Persistence
  • Reliability
